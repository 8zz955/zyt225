写法 / Usage

先用 data-lucide 标记图标名，再由本地脚本把它替换成内联 SVG。

<script src="cdn/lucide/lucide.min.js"></script>

<i data-lucide="feather"></i>

<script>
  lucide.createIcons();
</script>
SVG 图标的三件套

一个图标名称、一个本地脚本、一次 createIcons()。渲染结果是可被 CSS 直接控制的内联 SVG，颜色、描边与尺寸都随样式变化。
